# ChatBBC 2.1.18 Release Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish the merged upstream reliability port as ChatBBC 2.1.18 with synchronized metadata, reviewed notes, reproducible artifacts, and no unrelated changes.

**Architecture:** The release commit updates the five version owners checked by `publish.yml`, moves unreleased changes out of the already-published 2.1.17 changelog section, and adds the tag-owned release notes. The tag points at the reviewed release commit on `main`; `publish.yml` builds, smokes, hashes, and publishes every artifact from that tag.

**Tech Stack:** Electron, TypeScript, npm, GitHub Actions, GitHub Releases.

**Spec:** `AGENTS.md` §20 and `.github/workflows/publish.yml`

## Global Constraints

- Release version: `2.1.18`; tag: `v2.1.18`.
- Preserve `APP_TITLE = 'ChatBBC'`, `APP_SLUG = 'chatbbc'`, and bridge protocol `15`.
- Publish only from the reviewed tag using `.github/workflows/publish.yml`.
- Do not install or mutate the user's live application data.
