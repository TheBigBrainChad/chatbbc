# ChatBBC 2.1.17

The Superpowers skill pack — Jesse Vincent's [obra/superpowers](https://github.com/obra/superpowers) workflow skills, bundled and controllable from Settings.

## Added

**A bundled skill pack.** Fourteen skills ship with the app — brainstorming, writing-plans, executing-plans, subagent-driven-development, test-driven-development, systematic-debugging, using-git-worktrees, dispatching-parallel-agents, requesting-code-review, receiving-code-review, verification-before-completion, finishing-a-development-branch, writing-skills and using-superpowers. They are mirrored into the managed skill library on launch and selected from the composer with `/` as usual.

The prose is **adapted to ChatBBC**, not shipped verbatim: skill references use ChatBBC slash commands, `TodoWrite` becomes `update_plan`, and file/shell tools are named as ChatBBC exposes them. `subagent-driven-development` and `dispatching-parallel-agents` were partly rewritten, because their original instructions assume local code subagents that ChatBBC does not have — its workers are separate browser conversations in a star topology.

**A Skills section in Settings.** One row per skill, with an on/off switch, a separate switch for implicit invocation (whether ChatGPT may open a skill without being asked), and the size of the skill's body so a large one is never named blind. A skill you switch off moves to a "Turned off" group with a control to bring it back.

**One owner for the decision.** Whether a skill is used resolves in a single place, layered: your explicit choice, then an external Codex rule if one addresses it, then the skill's own declaration, then on by default. A disabled skill leaves both the composer's `/` list and the connector's advertised catalog.

## Fixed

- **The advertised catalog no longer lists skills you switched off.** The connector's handshake instructions were reading the unfiltered library, so a disabled skill was still offered and then failed when selected.
- **Regenerated `THIRD-PARTY-NOTICES.txt`.** It had gone stale and still carried a previous product name. `scripts/generate-third-party-notices.mjs` faithfully rebuilds it; shipping was never affected because packaging regenerates before building.

## Notes

- The pack is MIT licensed; attribution lives in `skill-pack/PROVENANCE.md`, `docs/licenses/superpowers/LICENSE`, and the notices file.
- Implicit invocation is scoped to a chat's opening message: the catalog is injected when a conversation starts, so ChatGPT cannot discover a skill mid-chat that it was not told about.
- A skill you edit is preserved across updates; the pack refreshes only the copies you have not touched.
