## Inline widget references

ChatBBC 2.1.21 fixes the raw `genui` JSON/HTML shown for ChatGPT's inline choice picker and other host-native widgets. Bridge protocol remains 17. Reload the companion shipped with this app.

### What changes

Assistant responses containing a complete or streaming `genui` content reference now show an inert “Rich content unavailable” card in the conversation instead of printing model-authored component source. Surrounding Markdown remains readable when the reference can be isolated; ambiguous or densely repeated references use one closed source disclosure. The exact recorded reference remains available under **Show original response source**; past recordings change on display without rewriting history. Literal examples inside code remain literal.

This release does **not** reproduce the interactive picker or send a selection to ChatGPT. To use its actual controls, open that conversation in ChatGPT. `app_block` HTML, scripts, iframes and unknown widget payloads are never executed by ChatBBC. Native choice and Continue remain inert.

### Related response families

OpenAI's [native inline visualizations reference](https://github.com/openai/role-specific-plugins/blob/main/plugins/data-analytics/skills/visualize-data/references/native-inline-visualizations.md) documents `app_block` and `charts_widget_v2` under the same `genui` envelope. This release gives those and other `genui` families the same safe fallback; it does not claim visual fidelity or live provider interaction. Citations, ordinary Markdown, recorded rich semantics and generated images retain their existing paths.

### Limits

The Chromium fixture and renderer tests cover local presentation; signed-in provider interaction, installed-app GUI acceptance and native widget submission were not verified for this tag. Linux x64/arm64 packages and their release artifacts are built and attached by the tag-scoped release workflow, not by this note.
