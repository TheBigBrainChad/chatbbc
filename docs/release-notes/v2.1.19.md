## Bounded rich capture

ChatBBC 2.1.19 ships bounded rich-answer capture, Recording Off observation fences, and
bridge protocol 17. Native choice and Continue stay inert. Reload the companion shipped
with this app.

### Rich answers stay on the canonical assistant shard

Supported ChatGPT answers can now carry a bounded semantic tree and PAGE media on the
same assistant message. An available preview requires complete PAGE custody. If the
page-local queue drops the last same-slot receipt, the companion recaptures those
pixels and retires the pending source lease. Saved previews open in a local viewer;
they may be smaller than the provider original.

### Recording Off keeps the committed prefix

Turning Recording Off no longer drops already-committed page and native image
evidence, in-switch finals, or accepted observation rows. A later generation cannot
write its pixels into the earlier recording.

### Native actions stay inert

The app can show read-only rich action status and PAGE retry eligibility. Production
`begin`/`elect`/`arm` remain unregistered. There is still no trusted app gesture or
matched original-page postcondition for native choice or Continue. Do not expect
those controls to run from ChatBBC in this release.

### Protocol 17 and Linux packaging

The app and companion now speak bridge protocol 17. Protocol 16 added bounded rich
observations; 17 adds authenticated recording generations before observation and
positional journal admission after Recording Off. A 2.1.18 companion is refused
until you reload the copy shipped with this app.

Linux DEB packages prefer `libasound2t64` on Ubuntu 24.04 so Electron is not bound
to an ABI-incompatible OSS4 ALSA provider. The reviewed GVDB corresponding-source
archive is tracked in the tree.

### Limits

Signed-in companion pairing, provider-generated single/gallery/image-only pixels,
native choice/Continue postconditions, and installed raster/accessibility were not
verified on a live ChatGPT session for this tag. Unproved families remain
explicitly unsupported.

native-source archive, and `SHA256SUMS.txt` are attached below.
