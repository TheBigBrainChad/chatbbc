## Reliable recovery and browser control

ChatBBC 2.1.18 brings the current upstream reliability work into the Linux-focused fork without changing its identity, bridge protocol, appearance, or skill-pack behavior.

### Responses stay attached to the work that produced them

A response observed across page or document replacement now keeps one canonical turn boundary. Native finals, interim prose, local tool calls, completion state, and expanded activity details agree on the same owner instead of drifting into the next response or appearing out of order.

Queued corrections and automatic Continue also keep one delivery owner. Recovery-generated input cannot be edited or reordered as if it were authored queue content, image injection accepts up to ten images, and closing a browser page deliberately pauses silence and Goal/input pickup until that page genuinely returns.

### Existing browser tabs are easier and safer to inspect

The Desktop browser tools can inspect existing HTTP(S) tabs—including protected ChatGPT pages and tabs attached by another local session—without claiming their debugger or changing focus. New-tab creation now reports requested navigation separately from debugger attachment, and navigation invalidates stale page references consistently.

Chromium can throttle screenshots after background input or layout changes. Screenshot capture now owns a tiny, capture-scoped compositor wake and stops it before returning. It does not select the tab, extend the timeout, or leave a stream running.

### Recovery waits for stronger evidence

Automatic compaction waits for exact native result receipts before interrupting a source page. Worker wakes recheck the current session and departure state after asynchronous reads. Extension observation batches retain a 60-second delivery window without weakening request or document ownership.

The pinned GVDB native-source archive now uses GNOME's byte-identical GitHub mirror after its original GitLab endpoint stopped serving the archive. The reviewed size and SHA-256 remain unchanged.
