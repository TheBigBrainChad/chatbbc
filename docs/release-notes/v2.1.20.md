## Crystal Studio

ChatBBC 2.1.20 ships the Adaptive Studio shell, response-owned image galleries, and
generated-image download and save. Bridge protocol stays 17. Native choice and Continue
stay inert. Reload the companion shipped with this app.

### Adaptive Studio

The rail, chat navigator, conversation stage, and contextual workbench keep the current
transcript mounted while you visit files, agents, usage, or settings. Appearance can follow
a live Omarchy theme. Supported Hyprland glass uses native transparency; other desktops keep
a readable atmospheric surface.

### Generated images

Images from one response stay together. Download an original through Chrome, or use Save
preview to write the recorded WebP copy to a file or folder you choose. A set over 20 images
requires an explicit selection of at most 20. The save never replaces an existing file.
Core `generated_assets` can list recorded images and create a new file in an approved folder
from a preview or the exact page's image source.

Save preview checks the currently selected chat and canonical image membership before and
after the file dialog. Gallery selection and an in-progress Save result survive timeline
regrouping. Download receipts stay exact after the companion reconstructs its status.

### Limits

Native choice and Continue remain inert. Production `begin`/`elect`/`arm` are not armed.

postconditions, provider-original fidelity, native compositor blur, and installed-app GUI
acceptance were not verified on a live ChatGPT session for this tag. Unproved families
remain explicitly unsupported.
