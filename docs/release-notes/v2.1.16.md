## Cheaper companion, working resumes

Two user-visible fixes, both ported from upstream, plus a handful of smaller ones.

### The companion stopped costing CPU

Tur Tur Sahur had been running a permanent animation loop. Every visible pet re-armed the
next frame at display refresh rate — including while its context menu was open and
nothing was moving — and each frame re-queried its menu and rewrote values that had not
changed.

It now sleeps until the next authored frame, phase or autonomous decision, and writes to
the DOM only what actually changed. Measured on this machine, idle fell from **165 to 2.7**
animation callbacks per second and an open menu from **165 to zero**; CPU for both dropped
to zero at the measurement's resolution.

The sprite atlas, per-frame durations, choreography, travel speed and reduced-motion poses
are untouched. The only behavioural difference is that a deliberate long hold now survives
a renderer stall instead of being cut short.

### Compact & Resume works again

ChatGPT's Markdown serializer escapes punctuation as it round-trips inserted text, so the
routing marker the app writes as `[[CLF-RESUME:<token>]]` was being read back as
`[[CLF-RESUME\:<token>]]`. Every reader matched only the unescaped form. The app therefore
failed to recognise its own resume bootstrap: the fold card that should have shown one
continuous session across the handoff was never built, and the raw marker stayed on screen.

Readers now accept either spelling and strip the exact span that matched, so an escaped
marker is removed as completely as a clean one while genuine backslashes in the brief
survive. The grammar stayed narrow on purpose: letters and digits cannot be escaped in
Markdown, so `\0`, `\a` and doubled backslashes are still refused.

A cross-runtime parity test now loads the companion's reader in a sandbox and asserts it
agrees with the app's on five accepted and eight refused shapes, so the two cannot drift
apart again.

### Smaller fixes

- Calls arriving through the **Plugins** connector are attributed to this app again; the
  list of the app's own connector names had been missing it.
- Duplicate error notices now dedupe when ChatGPT's alert text includes its own **Retry**
  button label.
- A Compact & Resume committed after its worker run ended no longer strands the fleet in
  the old chat.
- Broker reports for a chat superseded by Compact & Resume no longer create a shadow
  session.
- The transcript's tail reserve is measured correctly when eviction leaves less than one
  viewport of content, so prepending history no longer moves every visible message.

## Not included

Upstream's manual-close suspension and its Thinking-failed deadline change are deliberately
absent. Both reverse behaviour this repository documents as explicit user decisions, and
upstream's own first version of the close behaviour was replaced about two hours later — so
either taken alone would land a state upstream itself abandoned.

## Upgrading

Reload the companion extension and refresh your ChatGPT connector after updating.
