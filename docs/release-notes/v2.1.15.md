## A shell that belongs to your desktop

This release is also the first to ship the **ChatBBC** identity, which had been staged but never
released. That part is a hard cut, so read it first.

### The rename

ChatBBC is the name everywhere a person, installer, companion or ChatGPT connector reads it. It
installs **beside** Chat On Steroids and starts with an empty settings folder — sessions, settings,
secrets and pairing are not carried over.

To move across: delete the three Chat On Steroids connector apps in ChatGPT's Developer mode, create
the three ChatBBC ones with the MCP URLs Setup shows, refresh ChatGPT's connector snapshot, and load
the ChatBBC companion from **Open extension folder**. The old companion will not connect to this app;
it expects replies stamped with its own name and will report ChatBBC as not running.

### The redesign

The interface now takes the desktop's own idiom instead of arriving with one of its own. Corners are
square, because Hyprland's `decoration:rounding` is; structure is hairline rather than boxed;
navigation, labels and status are set in monospace while your own words and the model's prose keep the
typeface you chose. Six near-identical animation durations became two, so the reduced-motion setting
can actually reach all of them.

**It follows your live theme.** A new control reads the active Omarchy theme from the same files
`omarchy-theme-set` writes and uses its colours and terminal font. It is an explicit toggle with a
deliberate refresh button — no watcher, and no silent repaint while you are working. Your saved colours
are never overwritten, so turning it off restores exactly what the pickers show.

**Two things the interface had never shown are now visible.**

The transcript belongs to your local session, not to the ChatGPT chat it happens to be running in.
When a session has moved between chats, that now reads as a joint in one continuous column, with a
labelled header opening each frontend's run — so a Compact & Resume looks like what it is rather than
like a new conversation that follows another.

And a message's delivery stage is stated in words. A message waiting in the outbox, a message placed
in the ChatGPT composer, a message ChatGPT has accepted, and a message an active turn is holding are
four different things, and the app now says which one you are looking at instead of showing one
ambiguous icon.

**The shell was regrouped.** Six settings tabs became five destinations in a single sidebar rail; the
five stacked composer rows became one status line that opens when you want it; Files, Sub-agents and
Terminal became one tabbed panel, with the terminal taking the room it needs while selected; and the
twelve kinds of content the transcript carries each got their own accent, glyph and edge over one
shared geometry.

## Packaging

CI and release packaging are Linux only. The Windows and macOS targets were inherited from upstream
and are no longer maintained here.

## Upgrading

Reload the companion extension and refresh your ChatGPT connector after updating.
